# 설치파일(Setup.exe) 다시 만드는 방법

이 폴더에는 **하나의 설치파일**(`데이터시트다운로더_설치.exe`)을 만드는 데 필요한 소스가 들어 있어요.
완성된 설치파일은 `00. 배포용\데이터시트다운로더_설치.exe` 에 있습니다.

## 구성 파일
- `setup.iss` — Inno Setup 스크립트 (설치파일의 뼈대: 어떤 파일을 어디에 넣고 바로가기를 만들지)
- `start.vbs` — **바로가기가 실행하는 시작 파일**. launch.ps1을 완전히 숨김으로 실행해 **검은 콘솔창이 전혀 안 뜨게** 합니다.
- `launch.ps1` — 실행 조율(숨김): 최초면 준비 실행 → API 키 없으면 입력 → 앱을 **창 없이(pythonw)** 실행
- `progress.ps1` — 최초 준비 중 보여줄 **GUI 진행창**(진행률 % 막대 + 숫자). 콘솔 대신 이 창만 보입니다.
- `setup_env.ps1` — Python 확인/설치 → 가상환경(.venv) → pip 패키지 → scrapling/patchright 브라우저 → **Chrome 없으면 자동 설치**
- `set_api_key.ps1` — 최초 실행 때 Mouser API 키를 입력받아 `.env` 생성

> 참고: `.ps1` 파일들은 **UTF-8 BOM**으로 저장해야 해요. Windows PowerShell 5.1이 BOM 없는 한글 스크립트를
> 시스템 코드페이지로 오독해 실행이 깨집니다. (다시 저장할 일이 있으면 BOM 유지 필수.)

## 설치파일이 받는 사람 PC에서 하는 일 (요약)
1. 코드·데이터·엑셀 템플릿을 `%LocalAppData%\DatasheetDownloader` 에 복사 (관리자 권한 불필요)
2. 시작메뉴·바탕화면 바로가기 생성
3. **바로가기 첫 실행 시**(인터넷 필요, 수 분): 검은 콘솔 없이 **GUI 진행창**만 뜬 상태로 —
   Python 자동 설치(없으면) → 패키지·브라우저 설치 → **Google Chrome 없으면 자동 설치** → Mouser API 키 입력 → 프로그램 실행
4. 이후 실행부터는 곧바로(창 없이) 프로그램이 뜸

받는 사람은 **자기 Mouser API 키**를 입력합니다(발급: https://www.mouser.kr/api-search/). 내 키는 배포물에 들어있지 않아요.

## 다시 빌드하려면
필요 도구: [Inno Setup 6](https://jrsoftware.org/isdl.php) (`winget install --id JRSoftware.InnoSetup -e`)

1. 빌드 작업 폴더를 하나 만들고 아래 구조로 파일을 둡니다.
   ```
   빌드폴더/
     setup.iss
     app/                         ← 앱 소스 한 벌 (아래 "app에 넣을 것" 참고)
     assets/python-3.14.6-amd64.exe   ← python.org 공식 설치기 (내장용)
     output/                      ← 결과 Setup.exe가 여기 생김
   ```
   `app/` 에는 이 폴더의 `start.vbs`, `launch.ps1`, `progress.ps1`, `setup_env.ps1`, `set_api_key.ps1` 도 함께 넣습니다.

2. **app에 넣을 것** (`클로드 코더` 폴더에서, 아래만 복사 — `__pycache__` 제외):
   - `main.py`, `requirements.txt`, `Data_list_217F.xlsx`
   - 폴더: `ai`, `datasheet`, `diagnostics`, `excel`, `ui`, `utils`, `tools`, `vba`, `data`
   - 위 스크립트들(`start.vbs`, `launch.ps1`, `progress.ps1`, `setup_env.ps1`, `set_api_key.ps1`)
   - ❌ 넣지 않음: `.venv`, `.git`, `.env`, `logs`, `Download_ datasheets`, PDF들, 백업/예시 xlsx, `old`

3. Python 공식 설치기를 내려받아 `assets/` 에 둡니다.
   ```bash
   curl -L -o assets/python-3.14.6-amd64.exe https://www.python.org/ftp/python/3.14.6/python-3.14.6-amd64.exe
   ```

4. 컴파일:
   ```bash
   "%LocalAppData%\Programs\Inno Setup 6\ISCC.exe" setup.iss
   ```
   → `output\데이터시트다운로더_설치.exe` 생성.

## .env(Mouser API 키) 저장 위치 (2026-09-04부터)
`.env`는 프로그램 폴더(`{app}`, 즉 `%LocalAppData%\DatasheetDownloader`) 안이 아니라,
**`%AppData%\DatasheetDownloader\.env`**(로밍, 프로그램 설치 위치와 완전히 분리된 자리)에
만들어져요. 프로그램 폴더를 재설치/이동해도 API 키가 그대로 남아있게 하려는 목적이에요
(예전엔 프로그램 폴더 안에 있어서, 재설치하면 키를 다시 입력해야 했음).
`set_api_key.ps1`/`launch.ps1`/`utils/config.py` 세 곳이 전부 이 경로를 알아야 하니, 이 경로를
바꿀 일이 있으면 **셋 다 같이** 고칠 것. (구버전에서 업그레이드하는 경우를 위해
`utils/config.py`가 예전 자리(`{app}\.env`)도 2순위로 계속 확인하고, 찾으면 새 자리로 자동
복사해줘요 - 코드 마이그레이션 로직 참고.)

## Lite 판(웹 검색 기능 제외) — `lite/` 폴더 (2026-09-04 도입)
불특정 다수에게 배포할 이 버전은 데이터시트 자동 다운로드 중 "웹(DuckDuckGo) 검색으로 보완"
단계를 뺀 버전이에요(자동 웹 검색이 실제로 IP 차단 사고로 이어진 적 있어서) - Mouser 공식
API만 쓰고, 못 찾으면 참고 링크만 안내해요. 빌드 방법은 `lite/README.md` 참고 - 이 문서의
2~5번 단계와 거의 같고, `datasheet/downloader.py`와 `requirements.txt` 딱 둘만
`lite/downloader.py`/`lite/requirements.txt`로 바꿔치기하면 돼요.

## 참고 / 주의
- **버전 올릴 때**: `setup.iss` 의 `AppVersion` 을 바꾸세요.
- **필요 런타임 의존성**: Python 3.14, PySide6, scrapling(+patchright Chromium), 그리고 **실제 Google Chrome**
  (다운로드가 `real_chrome=True` 로 동작 — 첫 실행 스크립트가 Chrome이 없으면 winget → 실패 시 구글 공식 설치기를
  자동 다운로드해 무인 설치(관리자 권한 없이 사용자 설치)를 시도, 그래도 안 되면 안내).
- 첫 실행은 인터넷으로 ~1GB 패키지 + 브라우저를 받으므로 시간이 걸립니다(멱등: 실패해도 다시 실행하면 이어서 진행).
- 코드 서명이 없어 Windows SmartScreen 경고가 뜰 수 있어요("추가 정보 → 실행"). 회사 배포라면 코드 서명 인증서 사용을 권장합니다.
